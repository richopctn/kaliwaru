Tutorial Pemasangan

Cara Instal APK di Perangkat Kamu

1

Unduh File APK

Klik tombol Download APK via Sfile di atas dan tunggu hingga proses unduhan selesai di browser HP kamu.

2

Izinkan Sumber Tidak Dikenal

Buka file APK yang sudah diunduh. Jika muncul peringatan keamanan, pilih Setelan → Izinkan dari sumber ini.

3

Instal & Mulai Nonton

Tekan Instal, buka aplikasi kaliwaru.net movie, lalu pilih film favoritmu tanpa iklan.

1

Kirim APK ke Android TV

Unduh APK lewat HP terlebih dahulu, lalu kirim ke TV menggunakan aplikasi Send Files to TV (tersedia di Play Store HP & TV) atau melalui Flashdisk USB.

2

Buka File Manager di TV

Buka aplikasi File Manager (seperti FX File Explorer / X-Plore) di Android TV, cari folder Download, lalu klik file APK-nya.

3

Nikmati di Layar Lebar

Setelah terinstal, aplikasi siap digunakan menggunakan tombol arah (D-Pad) pada remote TV kamu.
